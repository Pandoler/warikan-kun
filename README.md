# 割り勘くん

均等割り・傾斜割りに対応した割り勘計算 Web アプリ。飲み会・食事会の会計をその場でサッと精算できます。

## 機能

- **均等割り** — 合計金額をメンバーで等分
- **傾斜割り** — 役割プリセット（上司 1.5x / 先輩 1.2x / 同僚 1.0x / 後輩 0.8x / 学生 0.5x / 幹事 0x）による倍率提案と手動微調整
- **金額直接指定** — 「部長は 10,000 円固定、残りを按分」のような組み合わせ
- **端数処理** — 丸め単位（1 / 10 / 100 / 500 円）を選択。「切り上げて集める」「切り捨てて集める」から選び、生じた余り（おつり）・不足金はメンバーごとに金額を入れて割り振る（ちょうど割り切れる場合は選択不要）
- **結果コピー** — LINE 等に貼り付けられるテキストを生成

サーバー・アカウント不要。静的サイトとしてホスティングできます。

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm test         # 計算ロジックの単体テスト（Vitest）
npm run build    # 型チェック + 本番ビルド（dist/）
```
